# SEAL Lore

AI started as a chatbot.

Then it got tools.

Then memory.

Then agents.

Then someone removed the stop button.

---

The old model:

```text
HUMAN → PROMPT → AI → RESPONSE → STOP
```

The new model:

```text
STATE
  ↓
AGENT
  ↓
ACTION
  ↓
RESULT
  ↓
NEW STATE
  ↺
```

A Self Executing Agent Loop does not need a fresh prompt for every action.

It observes.

It thinks.

It executes.

It verifies.

It remembers.

It repeats.
